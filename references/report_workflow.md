# Report Workflow Checklist

## Source Handling

- Treat official school templates as the source of truth for page order and required prompts.
- Preserve photos or scans that include handwritten data, teacher stamps, signatures, or student information.
- Use peer reports only as conceptual references and formatting guides.
- Keep a per-experiment page map before composing the final PDF.

## In-Place Pre-Lab Filling

- Match each answer to the original blank, line, or answer box.
- Overlay newly inserted answers with a light gray background.
- Keep existing handwritten pre-lab answers when they are already present in the correct location.
- Do not add teacher-facing labels that describe the assistant's editing process.

## Data Processing

- Transcribe the user's measured values before calculating.
- Answer every question printed in the template.
- Include necessary formulas, substitutions, uncertainty or error calculations, and concise conclusions.
- Highlight section or question headings with gray backing so graders can quickly find each answer.

## Final PDF QA

- Confirm page count and order against the official template.
- Render every PDF page to an image and inspect for overlap, clipping, blank pages, and unreadable text.
- Check that all inserted gray highlights are subtle and do not obscure source content.
- Confirm the final file name identifies the experiment and is suitable for submission.
